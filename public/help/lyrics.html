Lyrics with inline chords

Write lyrics, drop chords right where they change.

Type lyrics into a song the way you would write them anywhere. To put a chord over a word, wrap it in square brackets and place it inline, right where the change happens:

[G]Halfway down the [C]highway, [D]headlights on the [G]lake

When you print a lyric book, the chords lift up above the words where they belong, so the page reads like a proper chart instead of a code puzzle.

You do not have to chord every line, or any line. Plain lyrics print as plain lyrics. The brackets are an option, not a tax.
