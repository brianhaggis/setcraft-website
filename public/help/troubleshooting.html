Troubleshooting

When something will not open, activate, sync, or update.

The app will not open

If macOS blocks it, right-click the app and choose Open once. Setcraft is signed and notarized, so this is a one-time handshake.

Activation says it cannot reach the server

Check your internet, then confirm the key and email match your purchase. If you are mid-setup on the welcome screen and it still refuses, skip to the free version and activate from Backstage instead. Same key, same result.

Bandsintown will not sync

Make sure the artist name matches your Bandsintown profile exactly, and that the API key was copied in full. See Connect Bandsintown.

Updates

The first time you run Setcraft, it asks whether it may check for updates automatically. Say yes and it quietly handles them from then on. Say no and nothing ever phones home about updates. Either way, you can check on demand from the Help menu, under Check for Updates.

Still stuck

Yes, we are about to say it. Quit Setcraft and open it again. It works more often than anyone wants to admit. If it does not, email hello@getsetcraft.com and a human will read it, or use the in-app reporter. See Reporting a bug.
