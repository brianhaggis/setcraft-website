Building a setlist

Drag songs into sets, reorder, and save.

Open Build Setlist. Your library sits on one side, your sets on the other. Drag a song across to drop it into a set. Drag it again to move it. Drag it off to take it out. It is exactly as fiddly as arranging songs on a napkin, minus the napkin.

A setlist can hold up to four sets, which covers everything from a coffee-shop single to a four-set wedding marathon. Reorder within a set by dragging, and the running order updates as you go. Each set header shows a running length, and the setlist header totals the whole show; see Song lengths and set times.

Playing a song twice

The same song can appear more than once. Drag it in again for the reprise, and each copy holds its own slot, counts as its own play in the song's history, and counts against the 15-song cap on a free setlist. Two performances, two entries. The math does not care that it is the same tune.

Hiding used songs

The library hides songs already in the setlist, so the list shrinks as the set fills. To see everything, untick Hide songs already in this setlist in the library filters. Songs in use then show an In set chip, with a count when a song is in there more than once.

Saving is manual. Hit Save when you are happy, so an experiment never overwrites the version you meant to keep. When it is saved, print it, export a PDF, open a tech cue sheet, or preview the transitions between songs, straight from the bar at the top. See Audio and transition previews.
