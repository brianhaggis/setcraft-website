Printing and PDF export

Setlists, lyric books, and chart books, on paper or as PDF.

From a saved setlist, choose Print / PDF. You can print the setlist itself, and optionally append a lyric book (every song's lyrics, in set order) and a chart book (every song's chart, in set order). Tick the boxes for what you want bound together.

On the Mac app this opens the real macOS print dialog, so you can send it to a printer or save it as a PDF, with a live preview, the same as any other app. Wherever a PDF is offered you will also find AirDrop, to hand it to a phone or another Mac, and Email, which opens a new message with the PDF already attached.

Options

The print dialog has toggles for the key, capo, notes, band name, venue, date, and song numbers, so the sheet carries exactly what you want and nothing else. Sharpie mode prints the setlist in a bold handwritten marker font, like it was scrawled on the spot, only legible.

Print defaults

Set your usual choices once in Backstage, on the Print/Export tab, with a live sample preview. Choices you save from the print dialog land there too, so every show does not start with the same five clicks. Paid printouts come out clean. The free version and the trial add a watermark overlay across each page.
