Notes and saved defaults

Drop notes between songs, and reuse the ones you repeat.

Some of the setlist is not songs. It is "tune down a half step here," or "thank the openers," or "do not start the next one until the crowd settles." Hover between two songs in a set and a + appears. Click it and a window opens where you can write the note, and it lands at that spot. An empty set shows a visible + Add a note hint instead, since there is nothing to hover between yet. Click any placed note to edit it.

Notes that take time

Some notes take stage time, like band intros or a retune. Give the note a time, like "2:00", and it counts toward the set length alongside the songs. A note without a time counts as zero and does not affect the totals.

Saved defaults

If you write the same note every show, tick Also save as a reusable default when you add it. The next time you open the note window, your saved defaults are listed in the same window. Click one and it drops in at that spot. A saved default remembers its time too. Your future self, mid-set, will thank you.
